## Repositories

**[R-Programming](https://github.com/guru99-edu/R-Programming)** holds the 16 data files (CSV, SAS, SPSS, Stata) behind the [R tutorial](https://www.guru99.com/r-tutorial.html). They cover importing data, missing values, correlation, ANOVA, regression, decision trees, random forests, GLM and k-means.

## Try it in R

Every dataset loads straight from GitHub, so lesson code runs without a download step:

```r
base <- "https://raw.githubusercontent.com/guru99-edu/R-Programming/master/"
titanic <- read.csv(paste0(base, "titanic_data.csv"))
head(titanic)
```
